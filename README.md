# My Portfolio Website

Personal portfolio website for Syed Muhammad Mehmam — AI Engineer specializing in LLMs, RAG pipelines, LangGraph agents, and Computer Vision.

🔗 **Live site:** [syedmuhammadmehmam.site](https://syedmuhammadmehmam.site)

## About

A single-page portfolio site showcasing production AI engineering work — including RAG chatbots, LangGraph agents, computer vision APIs, and data engineering pipelines. Built to highlight real, production-shipped projects with live demo videos rather than tutorial-style work.

## Sections

- **Hero** — intro, availability status, core stats (years of experience, sessions processed, impact metrics)
- **About** — background summary and core specializations
- **Projects** — featured AI/ML projects with GitHub links, tech stack tags, and demo videos
- **Skills** — core technical strengths across LLM engineering, computer vision, and production APIs
- **Resume** — link to view/download resume
- **Contact** — inquiry details and social/freelance links

## Tech Stack

- HTML5, CSS3
- Bootstrap 5
- Bootstrap Icons
- AOS (Animate On Scroll)
- Swiper.js
- Isotope.js (project filtering)
- GLightbox
- Google Analytics (gtag.js)

## Running Locally

This is a static site — no build step required.

1. Clone the repo:
   ```bash
   git clone https://github.com/Mehmaam99/my-portfolio-website.git
   cd my-portfolio-website
   ```
2. Open `index.html` directly in a browser, or serve it locally:
   ```bash
   python -m http.server 8000
   ```
3. Visit `http://localhost:8000`
